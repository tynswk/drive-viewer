# ADR-0002 認証は認可コード＋PKCE、トークン交換だけ Cloudflare Worker

- 日付：2026-11-15
- 状態：採用

**状況**：静的サイトの PWA から Drive を読み書きするには OAuth のトークンが要る。iPhone のホーム画面アプリでも、ログインが長く保たれる必要がある。

**決定**：認可コードフロー＋PKCE を使い、code と refresh_token の交換だけを Cloudflare Worker（`drive-viewer-auth`）で行う。client_secret は Worker の secret にだけ置く。refresh_token は端末に保存する。

**理由**：refresh_token があれば、1時間ごとのログインが要らない。Worker は無料枠で足り、常駐もしない。

**捨てた案**
- Google Identity Services のトークンクライアントだけで済ませる案：access_token が1時間で切れ、取り直すたびにポップアップが出る。iOSのPWAではポップアップの挙動が不安定。
- client_secret を静的サイトに埋め込む案：公開リポジトリだとシークレットスキャンで無効化される恐れがある。

**影響**：GCP の同意画面は本番環境にしてある（テスト中だと refresh_token が7日で切れる）。未確認アプリの警告は初回に一度通す。2026-11-15、iPhone 実機でホーム画面から起動してのログインと、再起動後のログイン維持を確認した。
