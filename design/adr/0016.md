# ADR-0016 範囲の絞り込みと除外は、取得後に祖先フォルダをたどって行う

- 日付：2026-11-15
- 状態：採用

**状況**：Drive API の `files.list` は「あるフォルダの配下すべて」を一度に取れない（`'X' in parents` は直下だけ）。「最近」は範囲（例：Claude 配下）で絞り、`.git` などを除く必要がある。

**決定**
- 最近は、マイドライブ全体から `modifiedTime desc` で取得する（フォルダ以外、ゴミ箱以外、pageSize 100）。
- 取得したファイルの親IDから祖先をたどる。範囲のフォルダIDが祖先にあるかで絞り込み、`.git`・`node_modules`・`__pycache__` が祖先にあれば捨てる。
- フォルダは id→{name, parents} をメモリと localStorage にキャッシュする。知らない親はまとめて `files.get` で取る。
- 絞った結果が 40 件に満たなければ、次のページを最大5ページまで取る。

**捨てた案**：範囲の配下を再帰的に列挙してから更新日でまとめる案。フォルダが多いとAPI呼び出しが膨らむ。
