# ADR-0010 見た目は「鮮度」を主役にし、琥珀1色とシステムフォント

- 日付：2026-11-15
- 状態：採用（ダークの地の色は ADR-0012 で置き換え）

**状況**：UI UX Pro Max の推奨は、スレートの地に緑、JetBrains Mono、FAQページの構成だった。frontend-design の基準では、どの開発者ツールにも出る定番に当たる。

**決定**
- このアプリで一番効く情報は「いつ更新されたか」なので、そこだけ目立たせる。10分以内は琥珀色＋点、1時間以内は琥珀色。
- 色は白／青みグラファイト、墨色、補助グレー、アクセントの琥珀（#b8760f／#e3a23f）だけにする。
- 書体はシステムフォントにする。日本語が主体で、iOSの文字サイズ設定に追従させるため。Webフォントは読み込まない。

**捨てた案**：UI UX Pro Max の推奨（上記）。

**状態**：モックで本人に提示した段階。ここへの指摘は無いまま、画面遷移の変更（ADR-0008）だけが来た。
