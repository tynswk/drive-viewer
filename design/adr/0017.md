# ADR-0017 P1実装で決めた細部

- 日付：2026-11-15
- 状態：採用

P1の実装中に決めた、SPECに書いていなかった振る舞い。

1. **戻る操作と未保存の変更**：編集中にOS・ブラウザの「戻る」で抜けるときも、変更があれば破棄の確認を出す（ADR-0013 の ×・∨・下へ払うと同じ扱い）。
2. **変更の無い✓**：本文が編集前と同じなら、通信せずにそのまま編集を抜ける。版の確認もしない。
3. **大きいテキスト**：10MBを超えるテキスト・md・HTMLは開かず、「Driveで開く」にする（docs/app/kind.js の TEXT_MAX）。
4. **マージ中の更新**：衝突の画面を見ている間にさらに更新が入ったら、トーストで知らせ、最新の本文で差分を作り直す。
5. **更新の検出**：modifiedTime ではなく version を比べる。メタデータだけの変更では知らせない。
6. **キャッシュ**：画面本体と app/ はネットワーク優先にする（push がすぐ反映される）。vendor は stale-while-revalidate。SW の VERSION を上げると古いキャッシュを捨てる。

**理由**：1・2・4 は ADR-0013・0014 の「確認は失うものがあるときだけ」をそのまま広げたもの。6 は、push しても次の次の起動まで反映されないのを避けるため。
