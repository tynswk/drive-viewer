# ADR-0015 本番アプリはビルドなしの素のES Modulesで書き、ライブラリは docs/vendor/ に同梱する

- 日付：2026-11-15
- 状態：採用（PLAN.md の「Vite + TypeScript + Preact」を置き換える）

**決定**
- `docs/` に素の HTML・CSS・ES Modules（`docs/app/*.js`）で書く。ビルド工程は持たない。
- 外部ライブラリは、版を固定したファイルを `docs/vendor/` に置いて読み込む。対象は marked、DOMPurify、pdf.js（pdfjs-dist の legacy でないESM版とworker）。CDNから実行時に取りには行かない。
- アプリ本体は Service Worker でキャッシュし、ホーム画面から起動したときにネットワークを待たずに出す。

**理由**
- モック（docs/mock/）が素のJSで書かれていて、そのまま本番の土台にできる。
- ビルドが無ければ、手元でもエージェントでも `git push` だけで直して出せる。
- 同梱すれば、CDNの障害や版の変化に左右されない。

**捨てた案**：Vite＋Preact。画面が少なく状態も単純なので、ビルドを足すほどの利点が無い。
