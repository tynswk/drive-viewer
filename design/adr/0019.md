# ADR-0019 md内の相対リンクはアプリ内で開き、「戻る」で元のファイルへ戻る

- 日付：2026-11-15
- 状態：採用

**決めたこと**：md の相対リンクを、開いているファイルのフォルダを基準に Drive のパスとして解き、同じアプリの中でシートを開き直す。来た元のファイルはシートに積んでおき、「戻る」（OSの戻る・∨・下へ払う）で1つ前のファイルを開き直す。フォルダを指すリンクは、その中の `README.md` を開く。

**理由**：仕様書・ADRの相互リンクを辿るのが主な使い方。これまでは href をそのまま別タブで開いていたので、GitHub Pages 上の存在しないURLに飛んでいた。辿った先から元の文書へ戻れないと、相互リンクを読み比べられない。

**細部**：
- 相対の判定：スキーム（`https:`・`mailto:` など）、`//`、`/`、`#` で始まらないもの。
- `?` と `#` 以降は捨てる（見出しへのジャンプはしない）。`%xx` は戻してから名前で引く。
- 見つからなければ「リンク先が見つかりません」のトーストだけ出す。

**捨てた案**：
- 「∨」だけは来た元に戻らず全部閉じる：閉じ方で結果が変わると覚えにくい。辿る深さは数段なので、戻り続けても手間は小さい。
- 見出しへのジャンプ：marked が見出しに id を振らないので、別の拡張が要る。今は要望が無い。
