# ADR-0008 画面遷移は一画面のツリーと、タップした要素から覆うシート

- 日付：2026-11-15
- 状態：採用

**状況**：モック第1版では、modern-web-guidance の stack-drill-down に沿って、フォルダもファイルも左右に積んでいた。

**決定**
- フォルダは一画面のツリーで、下に連ねて開閉する。
- ファイルは、タップした行の矩形から広がって画面を覆うシートで開き、閉じると元の行へ縮む。左右のスライドは使わない。
- アニメーションは0.11〜0.15秒のイーズアウト（第1版の約2倍速）。

**理由**：2026-11-15 の本人の指示。〔解釈〕文脈を失わずに素早く覗いて戻る操作感を優先していると思われる。

**捨てた案**：stack-drill-down（左右に積む・スワイプで戻る）。
