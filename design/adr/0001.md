# ADR-0001 PCを経由せず Drive API を直接呼ぶ

- 日付：2026-11-15
- 状態：採用

**状況**：エージェントが書いたファイルは自宅PCの G:（Googleドライブのミラー）から Drive に同期される。スマホから見る経路は「PCのファイルを配る」か「Drive API」のどちらか。

**決定**：スマホの PWA から Drive API v3 を直接呼ぶ。

**理由**：PCが落ちていても見られる。常駐サーバーやVPNを増やさずに済む（本人は常駐を嫌う）。

**捨てた案**：PCにHTTPサーバーを立てて Tailscale／トンネルで公開する案。PCが起きている必要があり、常駐が増える。

**影響**：PCで書いた直後は、Drive への同期待ちの分だけ遅れて見える。
