# ADR-0004 動画・音声は Service Worker で Range を中継し、Content-Range を組み立て直す

- 日付：2026-11-15
- 状態：採用

**状況**：`<video src>` には Authorization ヘッダを付けられない。Drive の `alt=media` はトークンが要る。

**決定**：SW が `stream/{fileId}` を受け、Range 付きで `alt=media` に中継する。Google の応答の `Content-Range` は CORS で SW から読めないので、`files.get?fields=size` でサイズを取り、Content-Range を自前で組み立てる。

**理由**：全体をダウンロードせずに再生とシークができる。2026-11-15、PC版Chromeで音声のシークを、iPhone実機で動画の再生・シーク・PiPを確認した。

**捨てた案**
- Blob で丸ごと取得する案：大きい動画だと再生まで待たされる。
- `access_token` をクエリに付ける案：トークンがURLに出る。
