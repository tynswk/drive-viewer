# ADR-0006 HTMLは scripts だけ許した sandbox の iframe（srcdoc）で描画する

- 日付：2026-11-15
- 状態：採用

**決定**：`<iframe sandbox="allow-scripts" srcdoc=...>` で描画する。`allow-same-origin` は付けない。

**理由**：エージェントが書いた HTML がアプリのトークン（localStorage・Cache）に触れられないようにするため。

**影響**：同じフォルダの css・画像を相対パスで読む HTML は崩れる。相対パスの解決はP3で検討する。
