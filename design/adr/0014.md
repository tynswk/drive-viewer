# ADR-0014 衝突したら差分を見せ、3方向マージで取り込ませる

- 日付：2026-11-15
- 状態：採用（ADR-0007 の「選ばせる」を具体化する）

**決定**
- 保存時の衝突では、全画面の差分画面を出す。
- 編集を始めた時点の本文（base）・自分の本文（mine）・Driveの最新（theirs）で3方向マージを行う。片方だけの変更は自動で取り込み、両方が同じ箇所を変えたときだけ「相手／自分／両方」を選ばせる（既定は両方）。
- 操作は「最新を読み込む」「自分の版で上書き」「マージして保存」。

**理由**：2026-11-15 の本人の指示。「衝突はdiffを表示。マージの選択肢も欲しい」。エージェントが追記し続けるファイル（計画書・メモ）では、変更が重ならないことが多い。重ならない分は人手で選ばせなくてよい。

**作り**：行単位。base–mine と base–theirs をそれぞれ LCS で対応づけ、両方で対応のとれる base の行を錨にして間の区間を比べる（diff3 と同じ考え方）。区間ごとに、mine が base と同じなら theirs を採り、theirs が base と同じなら mine を採る。mine と theirs が同じならどちらでもよく、それ以外は衝突とする。数千行までならブラウザで即座に終わる。

**捨てた案**
- 2者の差分（mine と theirs）だけを見せる案：どちらが変えたのかが分からず、片方だけの変更まで選ばせることになる。
- 文字単位のマージ：Markdown・コードでは行単位の方が読みやすく、結果も予測しやすい。
