# drive-viewer 仕様書

最終更新：2026-11-15（ピン留めの編集を追加）　／　関連：[DESIGN.md](DESIGN.md)・[adr/](adr/)

## 1. 目的

スマホで、AIエージェントが Google ドライブに書いたファイルをすぐ開いて確かめる。PCの前にいなくても、作業中のファイルを読み、軽く直し、メディアを聞きながら他のファイルも見られるようにする。

## 2. 利用者と環境

- 利用者は本人1人（本人の Google アカウント1つ）。
- 主な端末は iPhone で、ホーム画面に追加した PWA として使う。Android Chrome とPCのブラウザでも動くこと。
- 対象はマイドライブ全体。既定の範囲は `マイドライブ/Claude` 配下とする。

## 3. 機能要件

### 3.1 ログイン
- Google でログインし、ログイン状態を保つ。アプリを閉じて開き直しても、再ログインは不要。
- ログアウトできる。

### 3.2 最近（既定のタブ）
- 範囲内のファイルを、フォルダをまたいで更新日時の新しい順に並べる。
- 日付の見出し（今日／昨日／今週／それより前）でまとめる。見出しはスクロールしても上に残る。
- 各行には、種別アイコン・ファイル名・親フォルダのパス（範囲からの相対）・更新時刻を出す。
- 更新時刻の表し方は次のとおり。今日のものは相対（「今」「3分前」「2時間前」）、昨日のものは「21:40」、それより前は「11/12」。
- **鮮度の強調**：更新から10分以内は時刻を琥珀色・太字にして点を付ける。1時間以内は時刻だけ琥珀色にする。
- 範囲は左上のメニューで切り替える。候補はピン留めしたフォルダとマイドライブ全体。
- 新しいファイルが届いても、一覧に勝手に差し込まない。上に「新着 N 件」のピルを出し、押したら反映して先頭へ戻る。
- ファイル名で絞り込める（検索）。
- `.git`・`node_modules`・`__pycache__` の配下は出さない。

### 3.3 フォルダ
- 一画面のツリーで、フォルダを開くとその下に子を連ねる。ページ遷移はしない。
- 上にピン留め、その下にマイドライブのツリーを置く。
- フォルダ行を長押しすると、ピン留め／ピンを外すを選べる（ADR-0018）。
- フォルダ行には子の数、ファイル行には更新時刻（鮮度の強調つき）を出す。
- 開いているフォルダは、タブを切り替えても保つ。

### 3.4 ファイルを開く
- タップした行を起点に、その位置から広がって画面を覆うシートで開く。閉じると元の行へ縮んで戻る。左右へのスライド遷移は使わない。
- 閉じる操作は3つ。左上の「∨」ボタン、ヘッダを掴んで下へ払う操作、OS・ブラウザの「戻る」。
- ヘッダには、ファイル名・更新時刻・サイズと「…」メニュー（フルパス、リンクをコピー、Driveで開く）を出す。

| 種別 | 表示 | 切り替え・操作 |
|---|---|---|
| Markdown | レンダリング | 「表示｜生」、✎で編集 |
| テキスト・コード（txt, json, js, py, log など） | 等幅で生表示 | ✎で編集 |
| HTML | 隔離した枠の中で描画 | 「描画｜生」 |
| PDF | 縦に連続スクロール | 現在のページ番号を重ねて出す |
| 画像 | 画面幅に合わせて表示 | ピンチズームはOSに任せる |
| 動画・音声 | OS標準のプレーヤー | 速度のチップ（0.75〜2×）、PiPはOS標準 |
| その他 | 「Driveで開く」 | — |

### 3.5 編集（テキスト系）
- ✎で編集モードに入る。テキスト欄は内容に合わせて伸びる。
- 編集中はヘッダの✎が✓（保存。枠なしのチェック）に変わり、その左に×（やめる）が出る。どちらもいつでも押せる（無効にする理由が無いため）。
- ✓：保存して編集を抜ける。変更が無ければ何もせず抜ける。確認は出さない。
- ×：編集をやめる。変更が無ければそのまま抜ける。
- **確認を出すのは次の2つだけ**（→ ADR-0013）
  - 衝突：保存しようとしたとき、編集を始めた後にDrive側で書き換えられていた。全画面の差分画面を出す（→ ADR-0014）。
    - 編集を始めた時点の本文を基準に、自分の変更と相手（Drive側）の変更を突き合わせる（3方向マージ）。
    - 片方だけが変えた箇所は自動で取り込む。削除行は打ち消し線、相手の変更は琥珀、自分の変更は青の帯で示す。
    - 両方が同じ箇所を変えたときだけ、「相手／自分／両方」を選ばせる。既定は「両方」（何も失わない）。
    - 表示は「変更箇所（前後2行つき）／全文」で切り替える。見出しは衝突の数（無ければ「別の場所で更新あり」）。
    - 操作は「最新を読み込む」「自分の版で上書き」「マージして保存」の3つ。どれもいつでも押せる。∨で編集に戻る。
  - 破棄：変更があるまま、×・∨・下へ払う操作で抜けようとした。「破棄する／編集に戻る」を選ばせる。
- 編集中にDrive側で更新されたら、トースト「〇〇が別の場所で更新されました」だけ出し、再読込はしない（保存時に衝突として扱う）。

### 3.6 更新の追従
- ファイルを開いている間はDrive側の更新を見張る。更新されたら「〇〇が更新されました［再読込］」のトーストを出し、勝手に再読込はしない。

### 3.7 メディアのミニプレーヤー
- 動画・音声は全画面のシートで開く。「∨」か下へ払う操作で、下部のミニバーに収まる。再生は止まらない。
- ミニバーには、サムネイル（音声はアイコン）・ファイル名・再生位置・再生／一時停止・閉じるを出し、下端に進み具合の線を引く。
- ミニバーを押すか上へ払うと、全画面に戻る。
- ミニバーは、一覧の上でも、別のファイルを開いたシートの上でも出し続ける。
- 再生中のファイルは、一覧の行のアイコンを琥珀色にする。

### 3.8 ディープリンク
- `?id={fileId}` と `?path=Claude/dev/x/PLAN.md` で、そのファイルを直接開く。

## 4. 非機能要件

- **速さ**：アニメーションは0.11〜0.15秒のイーズアウトにする。長い一覧でもスクロールが引っかからないこと。
- **見た目**：ライトとダークはOSの設定に従う。ダークの地は完全な黒。グラデーションは使わない。アイコンは lucide を使う。説明文は付けない。
- **アクセシビリティ**：タップできる範囲は最低44px。iOSの文字サイズ設定に追従する。「視差効果を減らす」が有効ならアニメーションを切る。
- **安全**：client_secret は Cloudflare Worker にだけ置く。HTMLは scripts だけ許した sandbox で描画し、アプリのトークンに触れさせない。
- **費用**：無料枠に収める（GitHub Pages・Cloudflare Workers・Drive API）。

## 5. 対象外（今は作らない）

- ファイルの作成・削除・移動・共有
- 複数アカウント
- オフラインでの全文閲覧（最近開いたファイルのキャッシュはP2で検討する）
